## Featured Projects

**[CortexGuard](https://github.com/snehahibare/CortexGuard)** — Automated LLM safety auditing platform testing 275 adversarial prompts across 8 bias categories. Rule-based + LLM-as-judge scoring catches bias in up to 44% of cases missed by toxicity classifiers alone. Self-improving red-team loop with LlamaIndex retrieval achieves a 90.3% verified bias-fix rate without retraining.

**[Papyrix](https://github.com/snehahibare/papyrix)** — RAG system answering questions across multiple research papers with page-level citations, using sentence-transformer embeddings and ChromaDB. Embedding model fine-tuned via LoRA/PEFT on 224 domain-specific pairs, improving Recall@1 by 1.75%. Experiments tracked with MLflow.

**[ISL Translator](https://github.com/snehahibare/ISL-translator)** — Real-time Indian Sign Language translator recognizing 262+ gestures via LSTM sequence models and MediaPipe 126-point hand landmark extraction, achieving 90% accuracy. FastAPI backend optimized to 100ms inference, with NLP sentence generation and text-to-speech.

**[MedScan AI](https://github.com/snehahibare/Medscan-AI)** — Chest X-ray disease detection system using DenseNet121 on the NIH ChestX-ray14 dataset (112k+ images), achieving 0.82 mean AUC across 14 conditions. Includes Grad-CAM explainability and MC Dropout uncertainty estimation.
